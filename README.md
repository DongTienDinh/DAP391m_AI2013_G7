# Olist Brazil — Market Expansion Analytics & Forecasting

An end-to-end machine learning and strategic decision-support platform designed to forecast e-commerce revenue and rank Brazilian states for market expansion using the **Expansion Priority Score (EPS)**.

---

## Overview

This project solves the challenge of geographic market selection in the fragmented Brazilian e-commerce landscape. By aggregating transactional data from the Olist dataset with IBGE socioeconomic indicators, it provides:

1.  **Stable Forecasting**: State-level weekly revenue predictions using advanced regression models.
2.  **Strategic Ranking**: The **Expansion Priority Score (EPS)**, a composite index optimized via Entropy Maximization (SLSQP).
3.  **Explainable AI (XAI)**: Strategic narratives generated by Gemini (LLM) and aligned with SHAP feature attribution to provide "why" behind every recommendation.
4.  **Interactive Dashboard**: A Streamlit-based "Command Center" for real-time what-if analysis and spatial visualization.

---

## Datasets & Sources

The pipeline requires three primary data sources:

1.  **Olist E-Commerce Dataset (Kaggle)**: Transactional data covering 2016–2018.  
    > [kaggle.com/datasets/olistbr/brazilian-ecommerce](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce)
2.  **IBGE Socioeconomic Data (Basedosdados)**: State-level Population and GDP metrics.
    *   **Population**: [br_ibge_populacao](https://basedosdados.org/dataset/d30222ad-7a5c-4778-a1ec-f0785371d1ca?table=b99f0017-e587-477e-8cfb-05fb5d1005b8)
    *   **GDP**: [br_ibge_pib](https://basedosdados.org/dataset/fcf025ca-8b19-4131-8e2d-5ddb12492347?table=93007431-7ce9-42ee-8740-8c2274d345ad)
3.  **Brazil Geographic Boundaries**: GeoJSON polygons for all 27 states.  
    > Automated download via `python scripts/download_geojson.py`.

---

## Architecture & Pipeline

The project follows a modular, script-based pipeline:

1.  **Ingestion & Cleaning** (`run_cleaning.py`): ETL process handling Kaggle downloads, null imputation, and data validation.
2.  **Feature Engineering** (`run_features.py`): Generates a 35+ feature panel including lags, rolling windows, and demographic indicators.
3.  **Predictive Modeling** (`run_training.py`): Evaluates 9 models (CatBoost, LightGBM, Random Forest, etc.) using walk-forward cross-validation.
4.  **EPS Scoring** (`run_scoring.py`): Optimizes weights for Demand, Growth, Momentum, and Penetration to rank expansion targets.
5.  **XAI Generation** (`run_xai.py`): Synthesizes strategic narratives and SHAP alignment reports.

git clone https://github.com/DongTienDinh/DAP391m_AI2013_G7
cd DAP391m_AI2013_G7

# Setup virtual environment
python -m venv .venv

The project requires external assets and raw data:
```bash

python scripts/download_geojson.py

# Run Initial Cleaning (Downloads Olist data from Kaggle)
python scripts/run_cleaning.py
```
*Note: Ensure `data/external/` contains `br_ibge_populacao_uf.csv` and `br_ibge_pib_uf.csv`.*

### 3. Run the Pipeline
```bash
python scripts/run_features.py
python scripts/run_training.py
python scripts/run_scoring.py
python scripts/run_xai.py  # Requires GEMINI_API_KEY in .env
```

```bash
streamlit run app/streamlit_app.py
```

## Methodology: The Expansion Priority Score (EPS)

The EPS balances **Opportunity** against **Risk** using the following optimized logic:

$$EPS = (\sum w_i \cdot \text{Component}_i) \times (1 - \gamma \cdot \text{Logistics Penalty})$$

| Component | Metric | Definition |
| :--- | :--- | :--- |
| **PD** | Predicted Demand | Forecasted revenue + recent demand scale. |
| **GP** | Growth Potential | Short-term revenue velocity (velocity/acceleration). |
| **PG** | Penetration Gap | GDP-adjusted untapped market potential. |
| **MMI** | Market Momentum | Revenue efficiency per active seller. |
| **LC** | Logistics Cost | Normalized freight and delivery risk factor. |

**Weight Optimization**: Weights are found automatically by maximizing the **Shannon Entropy** of the ranking, ensuring the model effectively differentiates between states rather than clustering results.
